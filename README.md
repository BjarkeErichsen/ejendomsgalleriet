# Ejendomsgalleriet

Danish commercial real estate listing platform built with Next.js and Supabase.

## Quick Start


```bash
node --version
```

```bash
npm install
cd ejendomsgalleriet
npm run dev
```


environment must have 
NEXT_PUBLIC_SUPABASE_URL=https://.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=sb_publishable_...
SUPABASE_SERVICE_ROLE_KEY=sb_secret_....
